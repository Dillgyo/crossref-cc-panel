# 보충 기록: 논문 보충자료에서 뺀 표

2026년 10월 22일 보충자료를 재편하면서 본문이 인용하지 않는 세 표를 논문에서 빼고 이 문서로 옮겼다. 모두 `07_supplement.py`가 출력한다(출력 번호 표 S1, S2, S5). 수치는 그 출력(`supplement_out.txt`)을 옮긴 것이다. 판정 규칙과 패널은 논문과 같다.

## 2. 보완된 라이선스의 start 날짜 (스크립트 출력 표 S2)

대상은 보완 167,779건이다. 각 DOI에서 적격 CC 항목의 start 날짜 가운데 가장 이른 값의 연도를 패널 출판연도(2023년판 값)와 비교하였다.

| 구분 | 건수 | 비율 |
|---|---:|---:|
| start 연도 ≤ 출판연도 | 153,965 | 91.8% |
| 출판연도 초과이면서 2023년 미만 | 5,131 | 3.1% |
| 출판연도 초과이면서 2023년 이상 | 8,683 | 5.2% |
| start 연도 2023년 이상 전체 | 12,775 | 7.6% |
| 그중 출판연도도 2023년 이상 | 4,270 | |
| start 없음 | 0 | |

start 날짜는 라이선스가 적용되는 시점이며, CC 항목이 Crossref에 등록된 시점이 아니다.

2026년 10월 4일판 보충자료는 마지막에서 두 번째 행을 4,092건으로 적었다. 이는 다른 정의로 센 값이며, 두 정의의 대조는 `verify/s2_note.py`로 할 수 있다.
